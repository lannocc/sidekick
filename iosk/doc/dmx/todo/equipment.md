# Equipment to Buy

## Office Router + Network Switch

A highly-configurable and reliable switching office or small enterprise router from Miktrotik. Could be two separate devices but for our needs a single integrated router+switch should suffice.

### Subnets

Anticipating separation of the local network into subnets such as:

- server
- workstation
- demo
- wifi
- vpn
- dmz

## Demo Bank PC

A basic- to mid-range office PC to be used for simulating a PC at a bank. On this machine we can install other bank software that we might be likely to encounter. This machine can be used for testing the application as coming from a simulated bank network, doing in-house demo's, to explore potential app/system integrations, etc.

When not being actively demonstrated or tested, this machine could be used to keep one or more always-on dashboards (server/app/site monitoring, etc.) visible in the office. With that in mind, we probably want 2 screens (let one be always dedicated to the dashboard).

## Server

Our on-site server can fulfill many roles, though it probably will not be relied upon as a regular production end-point. It can be an active monitoring node. It can be a test bed for potential on-site deployment options. It can be used for local model training (if sufficiently powerful) and evaluation.

The server could be a stand-alone machine, or it can be part of a **server rack**.

## Server Rack

Optional. But having or not having a rack affects the chassis style (rackmount vs standalone) of the router/switch, server, and UPS:

- rack / mounting hardware
- cooling / ventilation ?
- server
- router
- switch
- patch panel
- cable management
- power conditioning / ups

## DevOps Workstation

A mid-range PC for app development, system administration, general management, etc. Hours upon hours may be continuously spent at this machine.

This workstation needs to be able to drive one or two large 4k monitors.

Also:
- adjustable height standing/sitting desk
- adjustable monitor swivel arms
- ergonomic roller chair

## VoIP Phone

A desk phone (corded handset) supporting VoIP/SIP.

## UPS

We'll want adequate UPS protection for the office router, server (standalone or rackmount), phone, and workstations. Multiple devices can share a UPS as long as the VA rating is adequate.
