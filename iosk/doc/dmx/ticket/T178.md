# Ticket T178: Number formatting / precision

- Status: **open**
- Workboard: **Diametrix**
- Column: **Interface / Visual**

## Description

From T170: We need to remove the two decimal places on all the $ cells (source and solutions), all ratios should have two decimal places.

This is actually bigger than that. We probably want to add some options to our custom types like Money, Percent, etc. so that we can specify different numbers of decimal places depending on where used, as needed.

## Comments

After discussion with David, we want to use full figures for all back-end calculations and any truncation/rounding would only happen on the final display to the front-end. We can capture money with cents for input purposes and still display the raw value in field history. We understand that sometimes this will cause someone who tries to do math right off the screen to be off by a small margin due to accumulated rounding errors.
