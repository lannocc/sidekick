# Ticket T236: Fixed-point arithmetic for Money

- Status: **open**
- Workboard: **Diametrix**
- Column: **Functionality**

## Description

Our "Money" type should actually be using fixed-point arithmetic rather than floating point. This is the only way to account for "every penny". Floating-point math is imprecise and can also give unexpected results when rounding because of its imprecise nature.
