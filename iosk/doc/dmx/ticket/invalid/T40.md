# Ticket T40: tunneled traffic

- Status: **invalid**
- Workboard: **Diametrix**
- Column: **Admin**

## Description

We might want to tunnel/proxy all traffic from the get-go with the first install. The primary benefit is to shield any network admin from seeing what services our local app connects to. Instead, they would see a single permanent connection to an address under our control.

## Comments

This was an early consideration for on-premises installs. Does not apply to the SaaS model.
