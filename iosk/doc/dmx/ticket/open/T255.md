# Ticket T255: Google processor migrations 9/24/25

- Status: **open**
- Workboard: **Diametrix**
- Column: **(Backlog)**

## Description

Google has now deprecated versions 1.2 and 1.3 of their pre-trained foundation models and these will automatically redirect to v1.5 starting on Sep 24, 2025.

We are currently using a v1.2 or v1.3 as the default (best-performing model) for these processors:

  - 1040 SCH E
  - 1065 SCH K-1
  - 4835
  - 1040 SCH F

So, prior to the migration date we should manually change the default on these processors to the second-best-performing model.
