# Ticket T229: Ability to clear (erase) field values

- Status: **open**
- Workboard: **Diametrix**
- Column: **Interface / Visual**

## Description

As I'm beginning work on T37 and T183 I'm confronted with the realization that putting drop-downs or checkboxes or anything else over the field inputs that restricts their values also might prevent erasure of a value. An empty value should not necessarily be a choice in each type of drop-down list, for the simple fact that any and every field must allow for empty data because the original source of data is scanned in and we have no control over what is filled out.

All that being said, would be nice to have a universal mechanism  that any field value can be cleared on demand.
