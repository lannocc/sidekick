# Ticket T105: Credit report items

- Status: **open**
- Workboard: **Diametrix**
- Column: **(Backlog)**

## Description

Improve credit report training on the THD sample for demo purposes.

Bring in addition fields for use on Summary screen too:

* Monthly settlement of debts
* Bankruptcies
* Late payments and other derogatory information

## Comments

Wait for more samples of credit reports so we can train this.

---

We now have fully labeled data set of (many repeated copies of) the single THD credit report sample from Factual Data. This gives our custom trained processor a score of only 0.905, which still beats the best Google score of 0.898 with their v1.3 processor. So this might be good enough to use the THD credit report for demo purposes but we should still expect some errors at this score.

The extra fields described above for this ticket we will still need to wait for other real credit reports to see how this information comes through. So this ticket is going to stay open... the Credit Report processor will need some significant training when we get more (actual) credit reports in the (actual) format the bank is going to use.
