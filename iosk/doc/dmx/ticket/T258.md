# Ticket T258: "Viewport"

- Status: **open**
- Workboard: **Diametrix**
- Column: **Interface / Visual**

## Description

Current paradigm is simply a collection of "screens" and embedded on each screen is one or more "views".

New paradigm is some screens might instead be "viewports" which have a single embedded table filling the screen. The viewport takes advantage of sticky table headers and columns for a better experience when scrolling.

Farm/Ag Cash Flow screen (T221) is a good candidate to work well in a viewport.

Support both paradigms.
