# Diametrix project status

### Last Status

**Reported:** 2025-09-24 08:47:11
**By User:** dmx

The Diametrix project is actively under development. The latest release, `v0.6.3`, was on September 3, 2025, with a focus on Farm/Ag functionality and UI improvements. Recent changes also include enhancements for bank user integration and developer features like a login bypass for local development. The backend is Python-based, and the frontend uses Svelte. Comprehensive documentation is available, which can be built from the `/dmx` directory.
