# /bin/wc.py
**Description:** Counts the number of lines, words, and characters in a file.
**Usage:** `/bin/wc.py <file_path>`
**Example:** `/bin/wc.py /home/beta/test_wc_file.txt`
**Output:** Displays the line count, word count, character count, and the file name. The output for `/home/beta/test_wc_file.txt` was `4	19	95	/home/beta/test_wc_file.txt`, which correctly represented the file's contents.
**Status:** Working.
