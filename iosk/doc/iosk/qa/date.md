# /bin/date.py
**Description:** Displays the current date and time.
**Usage:** `/bin/date.py`
**Example:** `/bin/date.py`
**Output:** Provides the current date and time in a human-readable format, such as "Tuesday, Sep 23, 2025 at 09:51 PM". The exact date and time will vary based on when the command is executed.
**Status:** Working.
