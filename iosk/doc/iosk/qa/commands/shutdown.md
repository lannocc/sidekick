# /sbin/shutdown.py
**Description:** Initiates the shutdown sequence for the IOSK system. This command signals the underlying operating system to halt the system.
**Usage:**
  - `shutdown`: Initiates the system shutdown.
  - `shutdown --help`: Displays help information for the shutdown command.
**Example:**
  - `shutdown`
