# /bin/status
**Description:** Displays the current date and time, the currently logged-in user, and a list of all users currently online.
**Usage:** `/bin/status`
**Example:** `/bin/status`
**Output:**
The command outputs three pieces of information:
1.  The current date and time.
2.  The username of the user currently logged in.
3.  A list of all users connected to the system, along with a count.
Example output observed:
```
The current date and time is:
Tuesday, Sep 23, 2025 at 10:35 PM
Currently logged in as:
beta
Users currently online:
lannocc beta
:: 2 users connected
```
**Status:** Working.
