# /bin/which.py
**Description:** Locates the full path to a command executable in the system's PATH.
**Usage:** `which <command>`
**Example 1:** `which ls`
**Output 1:** `/bin/ls.py`
**Example 2 (Error):** `which non_existent_command`
**Output 2 (Error):** `!! which: 'non_existent_command' not found in PATH`
**Status:** Working.
