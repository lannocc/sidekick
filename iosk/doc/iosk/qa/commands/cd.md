# /bin/cd.py
**Description:** Changes the current working directory. If no directory is specified, it changes to the user's home directory.
**Usage:** `cd [directory]`
**Example 1:** `cd /bin`
**Output 1:** `:: current directory changed to: /bin`
**Example 2:** `cd`
**Output 2:** `:: current directory changed to: /home/beta`
**Example 3 (Error):** `cd non_existent_dir`
**Output 3 (Error):** `!! cd: no such file or directory: non_existent_dir`
**Status:** Working.
