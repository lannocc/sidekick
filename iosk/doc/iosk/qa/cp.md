# /bin/cp.py
**Description:** Copies files or directories.
**Usage:** `/bin/cp.py <source> <destination>`
**Example:** `/bin/cp.py /home/beta/workspace/original.txt /home/beta/workspace/copy_original.txt`
**Output:**
- Successfully copied `/home/beta/workspace/original.txt` to `/home/beta/workspace/copy_original.txt`.
- Successfully copied `/home/beta/workspace/original.txt` into `/home/beta/workspace/test_dir/` as `/home/beta/workspace/test_dir/original.txt`.
**Status:** Working (file to file copy, file to existing directory copy).
