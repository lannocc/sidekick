# /bin/users.py
**Description:** Lists the usernames of all currently connected users to the iosk system. It also provides a count of the connected users.
**Usage:** `/bin/users.py`
**Example:** `/bin/users.py`
**Output:**
```
lannocc beta
:: 2 users connected
```
The output shows the usernames of connected users on the first line, followed by a line indicating the total count of connected users.
**Status:** Working.
